# 科研情报范围

## 工具与方法
GitHub Research Tools、AI for Science、Research Agents、MCP、Claude Skills、Codex Skills；文献检索、筛选、证据提取与管理；科研综述写作、论文结构、润色与引用核验；科学绘图、数据可视化与可编辑科研图；多组学、生物信息学与可复现分析。

## 学科重点
生物医学、药学、天然药物、药理学、化学分析；重点关注心肝轴、心血管疾病、肝脏疾病及相关跨器官机制。可关注代谢、炎症、信号通路等相关机制，但不得将其当作用户已确定的具体研究假设。

## 检索词参考（尚未配置为运行规则）
- 心肝轴：heart–liver axis、cardiohepatic、cardiac–hepatic crosstalk。
- 疾病：cardiovascular disease、heart disease、liver disease。
- 药学：natural products、natural medicines、pharmacology、chemical analysis。
- 方法：multi-omics、bioinformatics、literature search、systematic review、scientific visualization、research agent、Model Context Protocol、Claude skills、Codex skills。

关键词只是线索，不代表同时包含这些词的仓库就值得推荐；须结合用途、领域适配和证据。

## 来源与证据要求
优先论文原文、官方文档、原始代码仓库、Release 与可复现示例。社交媒体和汇总文章作为发现线索，重要结论回到原始来源核验。给出真实链接，不能把检索摘要当全文阅读，不能编造 DOI、指标、价格或支持能力；找不到来源写未知。

生物医学条目注明证据类型（体外/动物/人体，原始研究/综述/预印本），区分相关与因果、机制假说与已验证结论；不外推临床疗效。化学分析与多组学工具还应检查输入数据、格式、适用实验与复现条件。

## 推荐取舍
新旧均可；考察能否补足用户已有 Codex 与科研 Skills、安装及维护成本、模型费用、数据权限、许可证和学习门槛。使用“值得试 / 特定需求再用 / 暂无需增加 / 信息不足”等结论并说明证据。无充分依据时不声称提高若干倍效率。

不默认收集未发表数据、受试者信息、凭证或受限全文。关注范围调整由用户需求和后续任务记录驱动，不擅自扩大到与科研无关的热点。
